# Personal Cellar

A mobile-friendly app for keeping track of your wines.

- Each wine has a sequence, name, harvest, country, grape, bottle count and an optional picture
- Log purchases and bottles you drink, with a dated history
- Browse wines by sequence, harvest or country
- Analysis tab with pie charts (country, grape) and bar charts (harvest, monthly purchases and consumption)
- Export to Excel (Wines and Movements sheets) or import from Excel/CSV

The app is published as a Claude artifact, which stores the wines and pictures and handles Excel export:
https://claude.ai/artifact/9wjt9cgx4Jnzvej8RYwny8

`Personal Cellar.html` is a copy of the published page. If you open it directly in a browser, saving, pictures and Excel export are not available.
